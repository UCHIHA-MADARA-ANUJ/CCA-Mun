# MUN Command Center Peak

A modular Model United Nations skill suite for evidence-first research, country positioning, speeches, rebuttals, bloc strategy, negotiation, working papers, resolutions, amendments, procedure, crisis work, Drive-supported preparation, and final red-teaming.

## Contents

- `00_UPLOAD_READY_MUN_MASTER/` — always-on MUN master doctrine and command router.
- `skills/` — 40 specialist `SKILL.md` workflows.
- `MUN_PEAK_DEPLOYMENT_README.md` — deployment and testing guidance.

## Recommended use

1. Enable the master skill as the standing MUN foundation.
2. Enable only the specialist skills relevant to the current task.
3. Provide the assigned country, committee, exact agenda, simulation date, background guide, Rules of Procedure, and speech limit.
4. Use the initialisation command in the deployment guide.

## Principles

- Verify changing and consequential claims with authoritative sources.
- Never invent facts, sources, quotes, votes, resolutions, or country positions.
- Keep recommendations country-authentic, mandate-compliant, and historically date-valid.
- Be assertive about weak policy design while remaining diplomatic toward delegates.
